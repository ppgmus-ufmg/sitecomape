# 4º Fórum de Autoavaliação e Planejamento Estratégico — build estático

Este repositório é gerado automaticamente a partir de
[ppgmus-ufmg/ppgmus-ufmg.github.io](https://github.com/ppgmus-ufmg/ppgmus-ufmg.github.io)
a cada atualização do site (GitHub Actions). Contém o HTML/CSS/JS
já prontos para servir em qualquer servidor estático — por
exemplo, o site institucional do PPGMUS — sem precisar instalar
nada nem rodar build.

## Como usar

Baixe ou clone este repositório e aponte o servidor web para a
raiz dele — o `index.html` já está aqui, junto com `css/`,
`assets/` e as demais páginas.

## Importante

Não edite estes arquivos diretamente: qualquer alteração é
sobrescrita no próximo build automático. Mudanças de conteúdo
devem ser feitas no repositório de origem.
